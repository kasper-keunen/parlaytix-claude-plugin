# ParlayTix for Claude

The prediction market for tickets, inside Claude Code. Ask Claude to find fan tickets, start a purchase or request, set up a Scout watch, look up prediction-market odds or draft a Group Wager with friends.

## Install

In Claude Code:

```
/plugin marketplace add kasper-keunen/parlaytix-claude-plugin
/plugin install parlaytix@parlaytix
```

Then run `/mcp`, choose `parlaytix` and sign in with your ParlayTix account.

## How it works

- Claude reads and prepares. You confirm anything that moves money or a ticket on ParlayTix, signed into the same account; Claude gives you the link.
- A fan ticket's payment is upfront and at risk if its condition misses. A hit gets the real ticket, claimed from the card and delivered by email.
- Each kind of access has its own permission. Manage them under [AI agents](https://parlaytix.xyz/account?tab=agents) in your account.

## Requirements

Claude Code and a ParlayTix account.
